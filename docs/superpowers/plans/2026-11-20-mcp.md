# Jev Ultrafast MCP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans, task by task.

**Goal:** Run the original Jev browser agent through Python MCP with headless Chromium.
**Architecture:** Vendor the small upstream core with provenance; adapt transport and
text generation while preserving action validation. Wrap each run in MCP browse.
**Tech Stack:** Python 3.12, Playwright, MCP FastMCP, HTTPX, OpenAI Responses.
**Spec:** ../specs/2026-11-20-mcp-design.md

## Global Constraints
No commits/pushes; tests make no paid model calls; credentials stay out of source.
Execute inline in the requested empty repo, which has no HEAD to create a worktree from.

## Review Focus
Stale DOM must prevent input; invalid generated text must not be typed; failed
navigation must close Chromium; repeated WAIT must hit a budget; MCP stdout must
remain valid protocol data. Cover each in tests below.

policy while adapting its tightly coupled browser transport; no runtime monkeypatches.
Ruling: reuse the existing empty repository directly; user prohibited commits.

helper, MCP wrapper, examples and offline regression suite. Initial tests exposed
the missing Browser Harness replacement and legacy text provider; new integration

then fixed with focus identity checks and a watchdog for the owned browser process
tree. Follow-up review accepted both fixes and identified startup observation timeout
classification; a failing test reproduced it and the exception translation was fixed.

the scratch workspace. uv sync --locked succeeds. User must supply provider keys;
no paid model request, commit, push, or client configuration mutation was made.
